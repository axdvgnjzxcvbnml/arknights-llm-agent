## 3. 泛称/灵活位占位的处理（本批新增结构过滤）

MAA 部分作业的某些槽位不是具体干员，而是“需求描述”（灵活位），如
`【医师】精一满级及以上练度`、`医疗：精一满级及以上`、`医疗2`、`铁卫1`、`特种-伏击客`、`重装-守护者`。
这类动作无法执行，若入训会让模型学会输出“deploy 医疗：精一满级及以上”这类非法动作，必须剔除。

本批在原有 38 个职业/黑话精确词基础上，新增**零误伤的结构判据**（真实干员/召唤物/装置名不会命中）：

1. 含练度要求括号或关键词：`【…】 / 练度 / 精一|精二 / 满级 / 及以上 / 专三`；
2. “职业-分支”：`^(八大职业|铁卫)-[汉字2-6]$`（右侧限汉字，避开联动 Latin 名）；
3. “职业+编号”：`^(职业|奶|盾)[数字/一二三…]$`，如 医疗2、铁卫1、先锋二；
4. “短词：练度要求”：`^.{1,8}：.*(精[一二三]|满级|练度|级及以上)`（`御龙：雷狼龙` 等真实名因无练度词不命中）。

规则的保留/剔除均有用例断言（弦惊/障碍物/地刺/幻影/海嗣/麒麟X夜刀/御龙：雷狼龙 必留；上述占位必删）。
清洗后 train/eval 中结构占位复查为 **0**。

## 4. 已知保留项（按“宁漏勿错”不自动硬滤，交后续策展）

最终集约 20% 的动作其名字不是 460 个 PRTS 干员页之一，但其中**绝大多数是正当实体**，必须保留：

- 召唤物：`弦惊`（令的龙，1254 次）、`幻影`、`斯卡蒂的海嗣`、`重构体`、`流形`、`风雪之眼` 等；
- 地图装置/障碍物：`障碍物`、`地刺`、`干扰地雷`、`特制水上平台`、`共振装置`、`陷阱`、`改良型二踢脚`、
  `便携式补给站`、`阻流阀`、`爬行号·防护单元` 等；
- 联动干员/单位（本批爬取的 460 干员未覆盖联动）：`麒麟X夜刀` 等。

这些在 answer 中已正确表述为“放置该装置/召唤物，提供场地效果或额外阻挡”，不冒充干员。

**残留的少量纯泛称/黑话**（无练度标记、无法与装置用规则安全区分）：分支名裸用如 `铁卫 / 伏击客 / 守护者 /
强攻手 / 速射手 / 重剑手 / 远卫 / 法师`，以及少量黑话 `坦克 / 大奶盾 / 单奶1 / 投降先锋 / 推人特种 /
双击快活 / 任意高台 / 补伤害` 等，合计约百条量级。它们没有客观结构特征可与召唤物/装置区分
（例如“弦惊/陷阱/田地”同样是短名词，却是正当实体），强行词表过滤有误伤风险，故本批**保留并记录**。

后续如需进一步净化，建议用**策展白名单**而非黑词表：从 PRTS“召唤物/装置”页面与干员召唤物字段构建
token 白名单，凡非真实干员且非白名单实体的动作再判为泛称；或把这类“需求型灵活位”单列为弱权重数据。
此为 V100 首轮训练后的可选优化，不阻塞当前训练。

## 5. 证据分层（强制）

每条样本：动作 `fact:maa_job`（来自作业时间轴）、理由 `inferred:timeline_reconstructed`（反推，非作者原话）；
命中 PRTS 的关卡敌情/干员职业另标 `fact:prts`。retrieved/inferred 不得升级为事实，审计已逐类核对。

## 6. 结论

数据可直接用于 V100 LoRA SFT：无同关泄漏、机器校验 0 格式问题、证据分级正确、长度在预算内。
主要局限（不阻塞）：① 关卡敌情 PRTS 富化仅约 11%（活动/磨难关，动作事实仍完整）；
② 少量无标记泛称黑话保留（§4）。建议首轮训练后按 eval 表现再决定是否补活动关敌情与做 token 白名单净化。
