# 自我反思模板（Self-Reflect）

> 每步动作执行结束后调用，产物（Reflection）会作为 {{REFLECTION}} 喂给下一步慢思考，
> 形成"决策—执行—反思—修正"的闭环。

请对照下面的信息，复盘上一步决策：

- 上一步决策（含 reasoning）：{{PREV_DECISION}}
- 实际执行结果（每个动作成功/失败、失败原因）：{{EXEC_RESULT}}
- 执行后的最新状态：{{NEW_STATE}}

请回答：

1. 上一步的动作是否都成功执行？失败是因为坐标/手速，还是决策本身不可行
   （干员不在手牌、费用不足、格子非法、技能未就绪）？
2. 局势是否按预期发展（敌人被拦截、费用是否吃紧、有无漏怪/掉耐久）？
3. 引用的知识是否被证实有用，还是 retrieved/inferred 建议误导了判断？
4. 下一步应如何修正（保留/撤销/补强哪个位置，还是先等待观察）？

输出一个 Reflection JSON：

```json
{
  "verdict": "good",
  "issues": ["发现的问题，没有则留空数组"],
  "adjustment": "下一步的具体修正建议",
  "confidence": 0.0
}
```

`verdict` 仅可取 good / risky / bad：执行全成功且局势可控为 good；存在隐患为 risky；
动作失败或局势恶化（掉耐久/漏怪）为 bad。不要文过饰非——bad 也要如实标注，
宁可下一步更保守。
